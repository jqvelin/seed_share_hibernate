# Hibernate Seed Share Demo

Консольное приложение на Java 17, Hibernate ORM, PostgreSQL и HikariCP для управления базой данных проекта «Обмен семенами».

«Обмен семенами» — это социальная сеть для садоводов: участники регистрируют семена своих сортов, выставляют их на обмен, фиксируют факт передачи и оставляют отзывы о всхожести. В системе также ведётся база вредителей и болезней с рекомендациями по лечению.

## Требования

- Java 17 JDK
- Maven 3.9+
- PostgreSQL с базой `seed_share`

Параметры подключения по умолчанию:

```properties
url=jdbc:postgresql://localhost:5432/seed_share
username=postgres
password=postgres
```

Настройки задаются в `src/main/resources/META-INF/persistence.xml`.

## Как запустить

1. Убедитесь, что PostgreSQL запущен и база `seed_share` доступна (схема инициализируется скриптами `DDL.sql` и `DML.sql`).
2. Проверьте параметры подключения в `persistence.xml`.
3. Выполните команду:

```bash
mvn clean compile exec:java
```

Приложение подключается к уже существующей базе (`hibernate.hbm2ddl.auto=none`), поэтому схему оно не пересоздаёт. Восстановить исходное состояние можно из меню (пункт «Сброс БД»).

## Схема базы данных

Приложение работает со схемой `seed_share`.

| Таблица | Назначение |
|---------|------------|
| `plant` | Растения |
| `variety` | Сорта растений |
| `issue` | Вредители и болезни |
| `plant_issue` | Связь растений и проблем с рекомендациями по лечению |
| `gardener` | Садоводы |
| `seed` | Запасы семян |
| `exchange` | Факты обменов |
| `exchange_item` | Позиции обменов |
| `feedback` | Отзывы о полученных семенах |

Также используется ENUM `delivery_method_enum` (способ доставки).

## Что показывает приложение

### CRUD-операции

- создание садовода, растения, сорта, связи с проблемой, записи о семенах и обмена;
- чтение списков и поиск по `id`, `username` и составному ключу;
- обновление рейтинга садовода и названия сорта;
- удаление временных записей;
- batch-вставка связей `plant_issue` в одной транзакции;
- транзакция при регистрации обмена с уменьшением остатков пакетиков.

### Бизнес-запросы

1. Топ сортов по рейтингу.
2. Надёжность садоводов по отзывам.
3. Статистика обменов по способу доставки.
4. Рекомендации по лечению для выбранного растения.
5. Семена, доступные для обмена.
6. История обменов конкретного садовода.
7. Незавершённые обмены.
8. Самые активные садоводы.

## Hibernate-техники

| Техника | Где используется |
|---------|------------------|
| `EntityManagerFactory` / `EntityManager` | `HibernateUtil` |
| JPQL и навигация по связям | `BusinessQueryService` |
| Generic Repository (CRUD) | `GenericRepository` и его наследники |
| Составные ключи (`@EmbeddedId`, `@MapsId`) | `PlantIssue`, `ExchangeItem`, `Feedback` |
| Транзакции (`begin` / `commit` / `rollback`) | `ExchangeItemRepository`, `GenericRepository` |
| Пакетная вставка (`flush` / `clear`) | `PlantIssueRepository.batchInsert()` |
| Пул соединений HikariCP | настроен в `persistence.xml` |
| Прямой SQL через `Session.doWork()` | `DatabaseResetUtil` |

## Меню приложения

- `CRUD` — демонстрация базовых операций.
- `Запросы` — запуск бизнес-запросов.
- `Всё` — полный прогон всех демо-сценариев.
- `CRUD растений` — отдельное мини-демо для таблицы `plant`.
- `Сброс БД` — полное восстановление исходного состояния из `ddl.sql` и `dml.sql`.
